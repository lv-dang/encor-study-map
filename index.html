⚖️ Where the books differ

SD-WAN namesOCG and CRAM say vBond / vSmart / vManage; the v1.2 blueprint and INE say Validator / Controller / Manager. Expect the new names, sometimes with the old one in brackets. DNA vs CatalystCRAM says DNA Center; the blueprint says Catalyst Center. Same product. RADIUS portsRFC 1812/1813; older Cisco defaults 1645/1646. Pick 1812/1813 unless the question says legacy. MACsec SecTAGCRAM: 16 bytes. OCG: the SCI is optional, so 8–16 bytes. If asked for one number, pick 16. VLAN rangesPCG: normal 1–1005. CRAM: normal 1–1001, 1002–1005 reserved. Shaping inboundNot supported; police inbound instead. vrf forwardingWipes the interface IP. IP SLANo schedule = no probes. STP root vs HSRPMake the HSRP active switch the STP root for the same VLANs, or traffic takes an extra hop. NAT rolesip nat inside on the LAN, outside on the ISP. Swapped = no translations at all.
